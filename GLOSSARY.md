# Календарь звонков

Сервис, через который Гости бронируют встречи с Владельцем календаря.

## Язык

**Владелец**:
Человек, к которому записываются на встречи. У сервиса он один.
_Не говорить_: хозяин, администратор, host

**Гость**:
Человек, который записывается на встречу к Владельцу.
_Не говорить_: клиент, посетитель, пользователь

**Тип встречи**:
Вид встречи, который предлагает Владелец: название, описание и длительность в минутах.
_Не говорить_: услуга, событие, event type

**Бронирование**:
Занятый Гостем интервал времени у Владельца для одного Типа встречи. Два Бронирования никогда не пересекаются.
_Не говорить_: запись, заказ, booking

**Окно записи**:
Период, в котором Гость может забронировать встречу: 14 календарных дней начиная с сегодняшнего, сдвигается вместе с текущей датой.
_Не говорить_: горизонт, период бронирования

**Рабочие часы**:
Время по часовому поясу Владельца, в которое к нему можно записаться.
_Не говорить_: часы приёма, расписание

**Слот**:
Возможное время начала встречи выбранного Типа встречи внутри Окна записи и Рабочих часов; длится столько же, сколько Тип встречи. Слот свободен или занят.
_Не говорить_: окошко, таймслот
